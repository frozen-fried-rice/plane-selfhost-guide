# Excel VBA 版 QRコード発行アプリ（スタンドアロン）

外部ツール・外部API・外部ライブラリ（DLL/参照設定）を **一切使わず**、Excel の VBA だけで
QRコードを生成・表示・印刷できるアプリです。オフラインの端末でもそのまま動きます。

- ✅ **完全スタンドアロン** … ネット接続・追加インストール不要。社内の閉じた環境でも動作
- ✅ **軽量** … 画像部品を使わず「セルの塗り」で描画。マクロ有効ブック1つで完結
- ✅ **日本語OK** … UTF-8 バイトモードで符号化（漢字・かな・記号もそのまま）
- ✅ **カスタマイズしやすい** … CSVから一括発行。関数 `QR_Generate` を呼ぶだけで自作処理にも組込可
- ✅ **規格準拠** … 型番(バージョン) 1〜40 / 誤り訂正 L・M・Q・H に対応（ISO/IEC 18004）

> 本エンジンのロジックは Python に移植し、標準ライブラリ segno との
> ビット一致・実機系デコーダ zbar での読み取り一致を全型番・全レベルで確認済みです。

## 2. 導入手順（最初の1回だけ）

1. Excel を新規に開き、**マクロ有効ブック（.xlsm）** として保存する
   （「名前を付けて保存」→ ファイルの種類＝`Excel マクロ有効ブック (*.xlsm)`）。
2. `Alt` + `F11` で VBE（Visual Basic Editor）を開く。
3. メニュー **ファイル → ファイルのインポート** で以下2つを取り込む。
   - `src/mQRCode.bas`
   - `src/mQRApp.bas`
   （またはメニュー「挿入→標準モジュール」を2つ作り、各 .bas の中身をコピー＆ペーストしてもOK）
4. Excel 本体に戻り、`Alt` + `F8` → **`QR_Setup`** を選んで「実行」。
   → 操作用シート「**QRツール**」とボタンが自動生成されます。

> マクロ実行がブロックされる場合は、ファイル→オプション→トラストセンター→
> 「マクロの設定」で許可するか、ファイルの「信頼」を有効にしてください。

## 3. 使い方

### A. 1件だけ作る（単票）

1. 「QRツール」シートで入力：
   - **B3**：QRにしたい内容（URL・テキストなど）
   - **B4**：誤り訂正レベル `L`/`M`/`Q`/`H`（既定 `M`）
   - **B5**：余白（モジュール数、推奨 `4`）
2. **［QRコード生成］** ボタンを押す。
3. 「**QRコード**」シートにQRが描画されます。スマホで読み取り確認、そのまま印刷可。

### B. CSVから一括で作る

1. 「QRツール」シートで設定：
   - **B8**：CSVファイルのフルパス（例 `C:\data\qr_list.csv`）
   - **B9**：QR化する列番号（1始まり。例 `2`）
   - **B10**：見出しに使う列番号（`0`＝なし）
   - **B11**：先頭行を見出しとして飛ばす（`1`＝はい / `0`＝いいえ）
   - **B12**：CSVの文字コード（`UTF-8` または `ShiftJIS`）
2. **［CSVから一括生成］** ボタンを押す。
3. 「**QR出力**」シートに、行ごとのQRが縦に並んで生成されます。

サンプル `sample/qr_list.csv` は `label,content` の2列構成です。
この場合は **QR化する列＝2 / 見出し列＝1 / 先頭行を飛ばす＝1 / 文字コード＝UTF-8** に設定してください。

## 4. 印刷・見た目の調整

- QRは「正方形に近いセル」を塗って描いています（列幅 2.14 / 行高 15）。
- 大きく印刷したい場合は、生成後に **QR範囲の列幅・行高を同じ値で拡大**すれば、
  比率を保ったまま拡大できます（例：列幅 4.28・行高 30 など、列幅は行高の約 1/7 が目安）。
- 「余白（B5）」は QR 周囲の白枠です。読み取り安定のため **4 以上**を推奨します。

## 5. カスタマイズ（開発者向け）

エンジンは1つの公開関数だけを持ちます。自作の処理から自由に呼び出せます。

```vba
' 戻り値 m は 2次元 Boolean 配列。m(x, y) が True のセルが黒。
' x=列, y=行, 範囲は 0 〜 size-1  (size = バージョン*4+17)
Dim m As Variant
m = QR_Generate("https://example.com", "M")   ' 第2引数: "L"/"M"/"Q"/"H"

' 任意のシート・任意位置に描画（行, 列, 余白 を指定）
RenderQRToCells ActiveSheet, 2, 2, m, 4
```

応用アイデア：

- **セル値から自動生成**：シートの一覧表をループし、各行の値で `QR_Generate` → `RenderQRToCells`。
- **名刺・ラベル印刷**：セル位置を計算して1ページに複数QRを並べる。
- **他システム連携**：在庫番号・URL・vCard・Wi-Fi設定文字列などをそのまま渡すだけ。
  - Wi-Fi例：`WIFI:T:WPA;S:SSID名;P:パスワード;;`
  - メール例：`mailto:info@example.com`
  - 電話例：`tel:09012345678`
- **描画の高速化**：本描画は「行内の連続黒モジュールをまとめて1回で塗る」最適化済み。
  大量発行時は `Application.ScreenUpdating = False` に挟むと更に軽くなります
  （CSV一括処理では自動で無効化しています）。

### 文字コードについて
- QR自体は常に **UTF-8 バイトモード**で符号化します（日本語対応・最も汎用的）。
- CSV読込は **UTF-8 / Shift-JIS 両対応**（B12で切替、UTF-8 は BOM も自動除去）。
  Excelで「CSV UTF-8」保存したファイルはそのまま UTF-8 で読み込めます。

---

## 6. 制限・注意

- 収まらないほど長いデータ（UTF-8 で型番40の容量超）はエラーになります。
  内容を短くするか、誤り訂正レベルを下げてください（`H`→`Q`→`M`→`L` の順に容量増）。
- 数字/英数字専用モードは未実装（バイトモードで統一）。実運用上の読み取りには影響しません。
- 生成した「QRコード」「QR出力」シートは実行のたびに作り直されます（内容は上書き）。
