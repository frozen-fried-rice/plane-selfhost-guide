# xlsx → CSV 変換ツール（先頭2行を自動削除）

Windows でダブルクリック一発で、Excel ファイル（.xlsx / .xlsm）を CSV に変換し、
同時に **1〜2行目を削除** します。追加のインストールは不要です
（Windows 標準の PowerShell と、PC にインストール済みの Microsoft Excel を使います）。

## ファイル構成
| ファイル | 役割 |
|---|---|
| `変換.bat` | ダブルクリックで起動するランチャー |
| `xlsx2csv.ps1` | 実際の変換処理（PowerShell） |

## 使い方

### 方法A：同じフォルダに置いて実行
1. `変換.bat`・`xlsx2csv.ps1` と、変換したい `.xlsx` を **同じフォルダ** に置く
2. `変換.bat` を **ダブルクリック**
3. フォルダ内のすべての xlsx が、先頭2行を削除したうえで同名の `.csv` になります
   （例：`data.xlsx` → `data.csv`）

### 方法B：ドラッグ&ドロップ
- 変換したい xlsx を `変換.bat` の上に **ドラッグ&ドロップ** すると、そのファイルだけ変換します
  （複数ファイルの同時ドロップも可）

## 仕様・注意点
- 変換対象は **1番目のシート** です（CSV は1シートのみのため）。
- 出力は **UTF-8（BOM付き）** です。お使いの Excel が古い場合は自動的に環境の文字コードで保存します。
- 既に同名の `.csv` がある場合は **上書き** されます。
- 元の xlsx は変更されません（削除はメモリ上で行い、CSV にのみ反映）。
- 開いたままの xlsx があると変換に失敗することがあります。Excel で閉じてから実行してください。

## 削除する行数を変えたいとき
`xlsx2csv.ps1` の先頭付近にある次の行の数字を変更してください。

```powershell
# 先頭から削除する行数（ここを変えれば削除行数を調整できます）
$DeleteRows = 2
```

例：見出し1行だけ削除したいなら `$DeleteRows = 1` にします。

## うまく動かないとき
- 「Microsoft Excel が見つからない…」と出る → Excel がインストールされた PC で実行してください。
- 実行時に警告が出る場合 → バッチ経由なら通常は不要ですが、PowerShell を直接使う際は
  実行ポリシーの制限に注意してください（バッチ内で `-ExecutionPolicy Bypass` を指定済みです）。
